STEP 0 · 프로젝트 뼈대 — 설정 읽어오기

5분

내 PC에 main.py라는 파일을 만들고, .env에 적어둔 키워드·키를 프로그램이 읽어와서 쓸 수 있게 만드는 부분부터 시작한다. 여기서부터는 화면에 뭔가 뜨면 다음 단계로 넘어가도 된다.

여기서부터는 진짜로 코드를 짠다 — AI는 이렇게 쓴다

  1. 여기서 말하는 "AI"는 사내에서 쓰는 대화형 챗봇이다. 프롬프트를 넣으면 그에 맞는 파이썬 코드 파일(.py)을 다운로드할 수 있게 준다 — 이 페이지처럼 직접 실행해주지는 않고, 내 PC의 파일을 열어보거나 고쳐주지도 않는다.
  2. 아래 프롬프트를 복사해서 그 AI 채팅창에 그대로 붙여넣는다.
  3. AI가 내려주는 파일을 받아서, 내 PC의 news-report-bot/main.py 로 그대로 저장(덮어쓰기)한다.
  4. 다음 단계로 넘어갈 때도 같은 대화창에서 계속 이어서 물어봐야 한다. 새 대화를 시작하면 AI가 지금까지 짜준 코드를 기억하지 못한다. AI는 내 PC의 파일을 직접 열어보지 못하니, 매번 "지금까지 코드 전체를 다시 통째로 달라"고 요청해서 파일을 새로 받는 식으로 진행한다 (아래 프롬프트마다 이미 그렇게 요청하도록 되어 있다).
  5. 이 AI 툴은 질문마다 답하는 모델이 자동으로 바뀐다("스마트 라우팅"). 어떤 모델은 파일을 바로 첨부해주고, 어떤 모델은 파일 대신 채팅창에 코드를 텍스트로 그대로 보여준다. 파일 첨부 대신 텍스트로 나오면, 화면 위쪽에서 모델을 Gemini로 바꾼 뒤 같은 프롬프트를 다시 넣어본다 — 그래도 안 되면 이 페이지의 "정답 코드 파일 받기" 버튼을 대신 쓴다.
이 프롬프트를 AI에게 붙여넣기 
파이썬으로 DART·뉴스 정보 크롤링 및 메일발송 프로그램의 첫 부분을 만들어줘. 나는
프로그래밍을 전혀 몰라 — 기술 용어 없이, 아래 내용대로만 동작하게 만들어주면 돼.

이 프로그램을 실행하면, 사전 준비 때 키랑 이메일 주소, 관심 키워드 같은 걸 미리 적어둔 그
설정 파일을 읽어와서 그대로 써야 해. 그 설정 파일에는 이런 항목들이 있어:

- KEYWORDS: 살펴보고 싶은 키워드들 (여러 개면 쉼표로 구분해서 적어둠, 안 적었으면 없는 걸로)
- RSS_FEEDS: 직접 지정해둔 뉴스 사이트 주소들 (여러 개면 쉼표로 구분, 안 적었으면 없는 걸로)
- DART_WATCH: 공시를 지켜보고 싶은 회사 이름들 (여러 개면 쉼표로, 안 적었으면 없는 걸로)
- DAYS_BACK: 며칠 치 정보를 볼지 (안 적었으면 1일로)
- MAX_ITEMS: 메일 하나에 최대 몇 건까지 담을지 (안 적었으면 40건으로)
- DART_API_KEY, NEWSAPI_KEY: 발급받은 인증키 두 개
- MAIL_TO: 메일 받을 사람 (여러 명이면 쉼표로 구분)

그리고 나중에 모을 뉴스 기사나 공시들을 하나하나 깔끔하게 정리해서 다룰 수 있는 방법도
만들어줘. 각 항목마다 이런 정보를 담고 있어야 해: 어디서 가져온 건지, 제목, 원문으로
가는 링크, 언제 올라온 건지(아직 모르면 비워둬도 됨), 참고할 만한 짧은 메모(없으면
빈칸). 날짜는 "09/03 14:30"처럼 한국 시간 기준으로 보기 편하게 보여주고, 날짜를 모르면
그냥 "-" 라고 보여주면 돼.

또, 가끔 인터넷에서 가져온 글 속에 이상하게 깨진 것처럼 보이는 부분이나 알아보기 힘든
기호가 섞여 나올 때가 있는데, 그런 걸 깔끔한 일반 글자로만 보이게 정리해주는 기능도
만들어줘.

마지막으로, 지금까지 이 설정들이 잘 읽혔는지 눈으로 확인할 수 있게 키워드 목록을 화면에
띄워줘.

채팅창에 코드를 텍스트로 보여주지 말고, 지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 다운로드 가능한 파일(.py)로 첨부해서 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • pip install python-dotenv 로 라이브러리를 먼저 설치했다
  • python main.py 를 실행하면 .env에 적은 키워드가 그대로 화면에 뜬다

10분

처음으로 인증 키가 필요한 서비스를 써본다. 키가 있어야 이 서비스가 우리 요청을 진짜 사용자로 인정해준다. (NewsAPI.org 무료 플랜은 개발/테스트용이라 호출 한도가 있고, 최근 한 달 기사만 검색된다)

터미널에 먼저 입력 pip install requests
이 프롬프트를 AI에게 붙여넣기 
이제 NewsAPI.org라는 뉴스 검색 서비스에서 기사를 가져오는 기능을 추가해줘.

뉴스 API 키(NEWSAPI_KEY)가 비어있으면, "뉴스 API 키가 없어 건너뜀"이라고 화면에 알려주고
그냥 넘어가면 돼.

키가 있으면, 아까 설정해둔 키워드 목록(KEYWORDS)에 있는 단어 하나하나로 NewsAPI.org에
검색을 요청해서 관련 기사를 가져와줘. 이때 그 서비스가 정해둔 방식대로 키를 실어서
요청을 보내야 하고, 한국어 기사 위주로 최신순으로 가져오면 돼.

만약 키가 틀렸거나 서비스 이용 한도를 넘겼다는 응답이 오면 "검색 실패"라고 화면에 알려주고
그 키워드는 건너뛰고 다음 키워드로 넘어가줘. 인터넷 연결 자체가 안 되는 경우도 마찬가지로
알려주고 넘어가면 돼.

가져온 기사들은 아까 만든 정리된 형태로 하나씩 담아줘 — 제목은 깨끗하게, 링크는 원문
주소로, 발행 날짜/시간도 같이 넣고, 어디서 가져왔는지는 "NewsAPI"라고 표시해줘.

  • 키를 채우고 실행하면 "NewsAPI 몇 건" 이 나온다 (0건이면 키워드를 영문/일반 단어로 바꿔서 시도)

STEP 3 · DART 공시 API — 실무형 API 경험

15분

조건을 가장 많이 넣어서 요청해야 하는 서비스다. 결과가 여러 페이지로 나뉘어 오는 것과, '결과 없음'을 진짜 오류와 구분하는 것까지 다룬다.

이 프롬프트를 AI에게 붙여넣기 
이번엔 전자공시시스템(DART)이라는 곳에서 공시 목록을 가져오는 기능을 추가해줘.

DART 인증키(DART_API_KEY)가 없으면 "DART 키가 없어서 건너뜀"이라고 알려주고 넘어가.

키가 있으면, 오늘부터 며칠 치를 볼지 정해둔 만큼(DAYS_BACK) 거슬러 올라간 기간 동안의
공시 목록을 DART에 물어봐서 가져와줘. 지켜보고 싶은 회사 이름(DART_WATCH)을 적어뒀으면
그 회사들 것만 남기고, 안 적었으면 전체 다 가져와줘.

가져온 공시 하나하나도 아까 만든 정리된 형태로 담아줘 — 제목은 "[회사명] 보고서 이름"
형식으로, 링크는 그 공시 원문을 볼 수 있는 주소로, 날짜는 접수된 날짜, 메모에는 누가
제출했는지 넣어줘. 어디서 가져왔는지는 "DART"라고 표시하고.

몇 가지 주의할 점이 있어. 첫째, DART는 결과가 많으면 여러 번에 나눠서 주니까, 끝까지
다 받아와야 해. 둘째, 그 기간에 공시가 하나도 없다는 답이 올 수 있는데 이건 잘못된 게
아니라 정상적인 상황이야(주말이나 공휴일엔 흔한 일이야) — 그럴 땐 에러처럼 표시하지
말고 그냥 조용히 넘어가줘. 그게 아니라 진짜 문제가 생긴 거면(이상한 응답이 오거나
인터넷이 안 되면) 그때는 무슨 문제인지 화면에 알려주고 멈춰줘.

채팅창에 코드를 텍스트로 보여주지 말고, 지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 다운로드 가능한 파일(.py)로 첨부해서 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • DART_API_KEY 를 채우고 실행하면 에러 없이 "DART 몇 건" 이 찍힌다 (주말·공휴일엔 0건이 정상)
  • 그 기간에 공시가 없을 때 에러처럼 빨갛게 뜨지 않고 조용히 지나간다
  • DART_WATCH 에 회사명을 넣으면 그 회사 공시만 남는다

STEP 5 · 메일 조립 — 보기 좋은 이메일 만들기

10분

정리된 항목을 사람이 읽기 좋은 이메일 본문으로 바꾼다.

이 프롬프트를 AI에게 붙여넣기 
정리된 항목들을 사람이 보기 좋은 이메일 본문(디자인이 들어간 형태)으로 만들어줘.

- 맨 위에 "오늘의 이슈 리포트"라는 제목과, 오늘 날짜(한국어, 예: 2026년 09월 01일), 그리고
  총 몇 건을 모았는지 보여줘.
- 그 아래엔 표 형태로 각 항목의 출처, 제목(누르면 원문으로 이동하는 링크), 발행 시간을 보여줘.
- 너무 많으면 지저분하니까 MAX_ITEMS에 설정한 개수까지만 보여줘.
- 이메일은 별도 디자인 파일을 못 불러오니까, 디자인은 전부 본문 안에 직접 넣어줘.
- 제목이나 링크에 특수문자가 섞여 있어도 이메일이 깨지지 않게 안전하게 처리해줘.

STEP 7 · 새 아웃룩 대응 + 발송 마무리

10분

새 아웃룩(New Outlook)은 방금 만든 방식 자체를 지원하지 않는다. 그 경우를 감지해서 대신 처리해주는 안전망을 만든다.

이 프롬프트를 AI에게 붙여넣기 
방금 만든 자동 발송 방식은 "새 아웃룩(New Outlook)"이라는 최신 버전에서는 지원이
안 돼서 오류가 나. 그 경우를 대비한 대안과, 전체 발송 과정을 마무리하는 부분을 추가해줘.

1. 자동 발송이 안 될 때를 위한 대안: 제목·받는사람·본문이 이미 채워진 새 메일 작성 창을
   대신 열어줘서, 사람이 마지막 [보내기]만 누르면 되게 만들어줘. (본문이 너무 길면 일부만
   담고 "내용이 길어 일부만 담았다"는 안내를 붙여줘.)

2. 전체 발송 마무리:
   - 받는 사람이 하나도 안 적혀 있으면 "받는 사람이 없다"고 알려주고 그냥 끝내줘.
   - 윈도우가 아닌 컴퓨터에서 실행하면 "아웃룩 발송은 윈도우에서만 된다"고 알려주고 끝내줘.
   - 아웃룩 자동 조작에 필요한 게 설치가 안 되어 있으면 설치하라고 안내하고 끝내줘.
   - 아까 만든 자동 발송을 먼저 시도해보고, 성공하면 "자동 발송 완료"라고 알려줘.
   - 만약 새 아웃룩이라서 자동 발송이 안 되면, 그 사실을 알려준 뒤 방금 만든 대안(메일
     창 열어주기)으로 넘어가서 "메일 창 열기 완료, 보내기만 누르면 된다"고 알려줘.

채팅창에 코드를 텍스트로 보여주지 말고, 지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 다운로드 가능한 파일(.py)로 첨부해서 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • 클래식 아웃룩 PC에서는 창 없이 바로 자동 발송된다
  • 새 아웃룩만 있는 PC에서는 예외 메시지가 뜨고, 내용이 채워진 메일 창이 자동으로 뜬다
  • MAIL_TO 를 비워두고 실행하면 에러 없이 안내 메시지만 출력된다

STEP 9 · RSS 수집 추가하기 (보너스)

10분

시간이 남으면 해보는 추가 실습. 구글 뉴스는 키워드 검색 결과를 RSS로 내준다 — API 키 없이 돌아가는 소스를 하나 더 붙여본다. 연합뉴스·한국경제·매일경제처럼 특정 언론사만 보고 싶으면 .env의 RSS_FEEDS에 그 언론사 RSS 주소를 추가하면 된다.

터미널에 먼저 입력 pip install feedparser
이 프롬프트를 AI에게 붙여넣기 
지금 완성된 프로그램에 RSS 수집 기능을 추가로 붙여줘. 구글 뉴스는 검색한 키워드에
대한 결과를, 별도 프로그램 설치나 키 발급 없이도 받아볼 수 있는 방법(RSS)으로 제공해줘.
이 방법으로 키워드별 기사를 모아와줘.

직접 지정해둔 뉴스 사이트 주소(RSS_FEEDS)가 있으면 그것도 같이 포함해서 가져와줘. 특정
사이트에 문제가 있어서 못 가져오면 그 사이트만 건너뛰고 계속 진행해줘. 각 사이트에서 너무
많이 가져오지 않게 사이트당 가져올 개수를 적당히 제한해줘 (예: 10개).

가져온 기사들도 지금까지처럼 "항목" 형태로 정리하고 출처는 "RSS"로 표시해줘. 그리고 전체
수집 순서 맨 앞에 이 RSS 수집도 포함시켜서, 실행했을 때 결과 건수에 RSS도 같이 나오게
해줘 (RSS → 뉴스 API → DART 순서).

채팅창에 코드를 텍스트로 보여주지 말고, 지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 다운로드 가능한 파일(.py)로 첨부해서 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • pip install feedparser 를 실행했다
  • python main.py --dry-run 을 실행하면 [1/3] 수집 결과에 "RSS 몇 건"이 함께 찍힌다
  • .env의 KEYWORDS에 흔한 단어(예: 삼성전자)를 넣으면 0건보다 많이 나온다
