# 바이브 코딩 교육

AI에게 프롬프트로 지시해서 실제로 돌아가는 업무 도구를 만들어 보는 사내 실습 교육.

## 과정 목록

### 2시간 단기 — 이슈 리포트 봇 만들기

> [`news-report-bot/`](news-report-bot/) · 소요 120분 · 각자 PC 로컬 실행

키워드를 정해두면 **매일 아침 내 메일함으로 요약 리포트가 오는** 파이프라인을 직접 만든다.

```
DART 공시  ─┐
구글 뉴스   ─┼─→ 중복 제거 → 아웃룩 발송 → 내 메일함
```

수집 소스를 구글 뉴스 → DART 순으로 붙인다. 구글 뉴스는 인증키가 없어서 첫 성공을 가장
빨리 보고, DART에서 조건을 많이 넣어야 하는 실무형 API를 경험하게 된다. 하나가 막혀도
나머지로 완주할 수 있는 구조다. 시간이 남으면 **언론사 RSS를 추가로 붙여보는 보너스
실습**도 준비돼 있다.

**진행 순서 (120분)**

| 시간 | 내용 |
|---|---|
| 10분 | 오프닝 — 완성본이 메일을 보내는 장면 시연 |
| 10분 | 세팅 점검 — 발급받아 온 DART 키를 손에 들고 준비 (입력은 실습 중 프로그램 창에서 한다) |
| 45분 | 실습 1 · 수집 (구글 뉴스 → DART) |
| 45분 | 실습 2 · 메일 발송 (가장 많이 막히는 구간) |
| 10분 | 마무리 — 팀별 확장, 시간 남으면 추가실습(언론사 RSS) |

**교육 전에 미리 준비할 것** — 당일에 발급받으면 2시간 중 40분이 날아간다.

- **`파이썬 설치.bat` 더블클릭** — 파이썬과 라이브러리 3개까지 한 번에 끝난다
- DART 인증키 (뉴스는 인증키가 필요 없다)
- **아웃룩(클래식) 로그인 확인** — 사내망은 SMTP를 막아서, 로그인된 아웃룩 앱을 직접 조작해 보낸다 (윈도우 전용)
- 모니터링할 키워드 3개

자세한 발급 절차와 자주 나는 에러 대응은 [`news-report-bot/README.md`](news-report-bot/README.md) 참고.

**실습 안내 페이지** — 당일에는 [`DART 뉴스 크롤링 및 메일발송 프로그램 만들기.html`](DART%20뉴스%20크롤링%20및%20메일발송%20프로그램%20만들기.html) 파일 하나만 열어두면 된다.
저장소를 내려받은 뒤 **더블클릭하면 브라우저로 바로 열리는 순수 HTML 파일**이라, 인터넷이
없어도 보인다 (깃허브 화면에서 링크를 누르면 소스 코드로 보이니, 받아서 직접 열 것).
사전 준비 체크리스트부터 단계별 프롬프트·성공 기준·막혔을 때 볼 정답 코드까지 이 한 파일
안에 전부 있다. 코드는 여기 안 담겨 있고, 이 저장소의
[`news-report-bot/`](news-report-bot/)는 그 결과물이 어떻게 생겼는지 보여주는 완성본(정답)일 뿐이다.

## 설치 — 파일 하나만 누르면 끝

저장소를 통째로 내려받은 뒤(초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기) 폴더 안의
**`파이썬 설치.bat`**(맥은 **`파이썬 설치.command`**)을 더블클릭하면 끝난다.
2~3분 걸리고, 검은 창에 글자가 올라가는 동안 **창을 닫지 말 것.**
`준비 끝!` 이 나오면 완료다.

이 파일이 하는 일은 두 가지다.

1. **파이썬 설치** — 이미 있으면 그대로 쓴다. 버전은 최신이어도 된다.
2. **라이브러리 3개 설치** — `requests`, `feedparser`, `pywin32` (맥은 `pywin32` 제외).
   실패하면 `--trusted-host` 를 붙여 한 번 더 시도한다.

> **왜 라이브러리까지 미리 깔아두나** — 실습 중 `pip install` 이 사내망에서 막히면 그
> 단계에서 진행이 멈춘다. 하필 `pywin32` 가 필요한 메일 발송이 가장 많이 막히는
> 구간(45분)이라, 거기서 실패하면 후반부가 통째로 날아간다.
>
> **왜 `%PY% -m pip` 으로 깔까** — 방금 찾아낸 그 파이썬에 정확히 설치된다.
> 여러 버전이 깔린 PC에서 "설치했는데 없다"는 문제가 여기서 생긴다.

**버전은 최신이어도 된다.** 단, 사내망에서 돌리려면 코드에 한 가지 대응이 필요하다 —
보안 장비가 HTTPS를 가로채 재서명하는데(TLS 인스펙션) 그 인증서에 Authority Key Identifier
확장이 없고, 파이썬 3.13부터 `ssl.create_default_context()` 가 `VERIFY_X509_STRICT` 를
기본으로 켜면서 이 확장을 요구해 거부한다
([cpython#138193](https://github.com/python/cpython/issues/138193)).
실습 STEP 2 프롬프트가 이 대응을 처음부터 요청하도록 되어 있고, 완성본 `main.py` 에도
들어 있다. 자세한 내용은 [`news-report-bot/README.md`](news-report-bot/README.md) 참고.

> API 키·인증 정보는 파일을 미리 준비할 필요 없이, 실습 중에 만드는 프로그램 창의 입력
> 칸에 직접 입력한다. **코드 작성은 실습 자체의 일부**라서 미리 하지 않는다 —
> [`DART 뉴스 크롤링 및 메일발송 프로그램 만들기.html`](DART%20뉴스%20크롤링%20및%20메일발송%20프로그램%20만들기.html)의 단계별 안내를 따라 직접 만든다.

**설치 파일이 막힐 때의 대안** — [파이썬 설치 관리자(.msix)](https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix)
를 깔고 `py install 3`, 이어서 `pip install requests feedparser pywin32`.
사전 준비 페이지에도 같은 안내가 「막히면」 항목으로 들어가 있다.

**막혔을 때**

| 증상 | 해결 |
|---|---|
| `파이썬 설치.bat` 자체가 회사 정책에 막힌다 | 위 「설치 파일이 막힐 때의 대안」을 따른다 |
| `파이썬 설치.bat` 실행 중 `Windows 보안` — "파일을 복사할 수 없음 (인터넷 보안 설정으로 인해...)" | 브라우저로 받은 파일에 "인터넷에서 받음" 표시(Mark of the Web)가 붙어서 그렇다. 이 파일은 실행되자마자 스스로 이 표시를 지우게 되어 있어 대부분 자동으로 해결된다. 그래도 뜨면 파일 우클릭 → **속성** → 맨 아래 **차단 해제** 체크 → 확인 후 다시 실행. zip으로 받아도 압축을 풀면 표시가 그대로 옮겨가니 zip은 해결책이 아니다 |
| 창이 깜빡하고 바로 꺼진다 | 압축을 안 푼 채 ZIP 안에서 실행한 경우다. 압축을 먼저 풀 것 |
| 파란 경고창 `Windows의 PC 보호` | `추가 정보` → `실행` 을 누르면 된다 |
| 맥에서 파일이 안 열린다 | 터미널에서 `chmod +x "파이썬 설치.command"` 를 한 번 실행한 뒤 다시 더블클릭 |

설치가 잘 끝났는지는 검은 창의 마지막 줄로 확인한다 — `준비 끝!` 이 나오면 된 것이다.

## 참고

각 과정 폴더의 코드는 **완성본**이다. 실습에서는 이걸 그대로 복사하는 게 아니라
프롬프트로 처음부터 만들어 가고, 막혔을 때 갈아탈 안전망으로 쓴다.

> **주의** — 프로그램 창에 입력한 값은 같은 폴더의 `settings.json` 파일에 자동 저장되고,
> 여기엔 API 키가 그대로 들어간다. 각 폴더의 `.gitignore` 가 이 파일을 제외하도록
> 되어 있으니, 그 설정을 지우지 말 것.
