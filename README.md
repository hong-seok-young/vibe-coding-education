# 바이브 코딩 교육

AI에게 프롬프트로 지시해서 실제로 돌아가는 업무 도구를 만들어 보는 사내 실습 교육.

## 과정 목록

### 2시간 단기 — 이슈 리포트 봇 만들기

> [`news-report-bot/`](news-report-bot/) · 소요 120분 · 각자 PC 로컬 실행

키워드를 정해두면 **매일 아침 내 메일함으로 요약 리포트가 오는** 파이프라인을 직접 만든다.

```
DART 공시 ─┐
네이버 뉴스 ─┼─→ 중복 제거 → AI 요약 → 아웃룩 발송 → 내 메일함
RSS 피드   ─┘
```

수집 소스를 RSS → 네이버 API → DART 순으로 붙인다. RSS는 API 키가 없어도 돌아가서
**5분 안에 첫 성공**이 나오고, 네이버에서 헤더 인증을, DART에서 파라미터가 많은 실무형 API를
차례로 경험하게 된다. 하나가 막혀도 나머지로 완주할 수 있는 구조다.

**진행 순서 (120분)**

| 시간 | 내용 |
|---|---|
| 10분 | 오프닝 — 완성본이 메일을 보내는 장면 시연 |
| 10분 | 세팅 점검 — 발급받아 온 키를 `.env`에 채우기 |
| 30분 | 실습 1 · 수집 (RSS → 네이버 → DART) |
| 25분 | 실습 2 · AI 요약 (지시문을 바꾸면 결과가 달라진다) |
| 35분 | 실습 3 · 메일 발송 (가장 많이 막히는 구간) |
| 10분 | 마무리 — 매일 자동 실행 예약, 팀별 확장 |

**교육 전에 미리 준비할 것** — 당일에 발급받으면 2시간 중 40분이 날아간다.

- 파이썬 설치 (`python --version` 이 되는지)
- DART 인증키 · 네이버 Client ID/Secret · Claude API 키
- **아웃룩 발송 준비** — Azure 앱 등록(앱 ID·테넌트 ID)과 첫 로그인. 제일 많이 막히는 항목이라
  강사가 앱을 하나 등록해 두고 앱 ID를 공유하는 편이 빠르다
- 모니터링할 키워드 3개

자세한 발급 절차와 자주 나는 에러 대응은 [`news-report-bot/README.md`](news-report-bot/README.md) 참고.

## 참고

각 과정 폴더의 코드는 **완성본**이다. 실습에서는 이걸 그대로 복사하는 게 아니라
프롬프트로 처음부터 만들어 가고, 막혔을 때 갈아탈 안전망으로 쓴다.

> **주의** — `.env` 파일에는 API 키가, 아웃룩 로그인 토큰 파일에는 내 계정으로 메일을 보낼 수
> 있는 권한이 들어간다. 각 폴더의 `.gitignore` 가 두 파일을 제외하도록 되어 있으니, 그 설정을
> 지우지 말 것.
