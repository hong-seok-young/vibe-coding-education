# 사내 이슈 데일리 리포트 봇

바이브코딩 2시간 실습의 **완성본**. 더블클릭하면 뜨는 프로그램 창에서 버튼만 누르면 아래가 자동으로 돈다.

```
DART 공시   ─┐
구글 뉴스    ─┼─→ 중복 제거 → 아웃룩 발송 → 내 메일함
언론사 RSS  ─┘  (보너스)
```

사내에서 이미 쓰이는 **키워드 모니터링 메일링**, **경쟁사 동향 수집**, **데일리 뉴스 리포트**가
모두 이 구조다. 키워드와 받는 사람만 바꾸면 팀별 도구가 된다.

> 이 폴더의 코드는 실습에서 **직접 치는 게 아니라**, 막혔을 때 비교해 보는 정답이다.
> 실제 실습은 저장소 맨 위 폴더의 [`DART 뉴스 크롤링 및 메일발송 프로그램 만들기.html`](../DART%20뉴스%20크롤링%20및%20메일발송%20프로그램%20만들기.html) 파일을 열어,
> 단계별 프롬프트를 따라 AI와 함께 하나씩 만들어 간다.

## 1. 사전 준비 (교육 전에 미리)

### 인증키 발급 — DART 하나만

| 키 | 발급처 | 비용 |
|---|---|---|
| DART 인증키 | https://opendart.fss.or.kr → 회원가입 → 인증키 신청 | 무료 (1일 2만건) |

**뉴스는 인증키가 필요 없다.** 구글 뉴스가 키워드 검색 결과를 프로그램이 바로 받아갈 수
있는 형태로 내주기 때문이다 — 가입도, 키도, 호출 한도도 없고 한국어 키워드가 그대로 통한다.

> 뉴스 검색 API를 안 쓰는 이유 — NewsAPI.org는 언어 지정 값에 한국어(`ko`)가 아예 없어서
> (`ar·de·en·es·fr·he·it·nl·no·pt·ru·sv·ud·zh` 뿐) 넣으면 요청이 거절되고, 한국 매체
> 수집 자체가 빈약해 한국어 키워드는 0건이 흔하다. 네이버 검색은 품질이 가장 좋지만
> [NAVER API HUB](https://www.ncloud.com/product/applicationService/naverApiHub)로 옮겨가서
> 네이버 클라우드 계정이 필요하다(무료 한도는 1일 25,000회로 넉넉하다). 수강생이 준비할
> 게 없는 쪽을 택했다.

### 메일 발송 방식 — 로컬 아웃룩 자동화 (Gmail·비밀번호 불필요)

사내망은 대부분 외부 SMTP(메일 서버 직접 발송)를 막아둔다. 그래서 이 봇은 메일 서버에
직접 붙지 않고, **내 PC에 이미 로그인되어 있는 아웃룩(데스크톱 앱)을 원격 조작**해서
보낸다 — 사람이 아웃룩에서 새 메일을 쓰고 [보내기]를 누르는 것과 같은 동작을
스크립트가 대신 하는 방식이다. 비밀번호를 코드나 별도 파일에 저장할 필요가 없다.

**윈도우 PC**여야 한다는 조건은 그대로다 (아웃룩 자동화가 윈도우 전용 기능이라서).
그 다음부터는 **구버전(클래식) 아웃룩이냐 신버전(New Outlook)이냐**에 따라 동작이 달라진다.

| 아웃룩 버전 | 동작 |
|---|---|
| 클래식 (왼쪽 위에 `파일` 탭이 있는 예전 화면) | **완전 자동 발송.** 사람이 손댈 게 없다 |
| 새 아웃룩 (New Outlook) | 제목·받는사람·본문이 채워진 **새 메일 창을 대신 열어준다.** 마지막 [보내기]만 직접 누르면 된다 |

새 아웃룩만 설치돼 있으면 완전 자동 발송이 안 되는 이유가 있다 — 새 아웃룩은 클래식과
아예 다른 구조로 새로 만든 앱이라, 이 스크립트가 쓰는 원격 조작 방식(COM 자동화) 자체를
지원하지 않는다. 이건 스크립트의 한계가 아니라 새 아웃룩의 설계상 제약이다. 스크립트가
자동으로 그 상황을 감지해서 [보내기]만 누르면 되는 방식으로 대신 처리해 준다.

> 완전 자동 발송을 계속 쓰고 싶다면, 아웃룩 설정의 **"새 Outlook 사용해 보기"** 토글을
> 꺼서 클래식으로 되돌리는 방법도 있다.

> 맥에서는 이 발송 방식이 동작하지 않는다.

## 2. 설치와 실행

> **처음이라면** — 저장소 맨 위 폴더의 **`파이썬 설치.bat`**(맥은 `파이썬 설치.command`)을
> 더블클릭하면 파이썬 설치까지만 끝난다. 파이썬이 아예 없어도, 이미 있는데
> 오래됐어도 알아서 해준다.
> 자세한 내용은 [최상위 README의 「설치」 절](../README.md#설치--파일-하나만-누르면-끝) 참고.
>
> 라이브러리 설치(`pip install ...`)와 `main.py` 작성 자체는 실습의 일부라서 여기 포함되지 않는다.
> [`DART 뉴스 크롤링 및 메일발송 프로그램 만들기.html`](../DART%20뉴스%20크롤링%20및%20메일발송%20프로그램%20만들기.html)의 단계별 프롬프트를 따라 직접 만든다.
> 아래는 **이미 완성된 코드를 그대로 실행**만 해볼 때의 순서다.

```bash
# 1) 필요한 라이브러리 설치
pip install -r requirements.txt
#    사내망에서 인증서 오류로 막히면:
#    pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org -r requirements.txt

# 2) 프로그램 실행 — 더블클릭하거나
python main.py
```

> 교육에서는 이 라이브러리들을 **사전 준비 단계에서 미리 깔게 한다.** 실습 중 `pip install`
> 이 사내망에서 막히면 그 단계에서 진행이 멈추는데, 하필 `pywin32` 가 필요한 메일 발송이
> 가장 많이 막히는 구간이다. 각 STEP 의 설치 안내는 그대로 남겨두되 "이미 받아뒀으면
> 넘어가기"로 표시해둔다.

**파이썬 버전은 가리지 않는다.** 최신 버전으로도 그대로 돌아간다 — 아래 「사내망 대응」에서
처리한다. 창을 열면 결과창 첫 줄에 실제로 어떤 버전으로 돌고 있는지 표시된다.

### 사내망 대응 — HTTPS 검사 장비(TLS 인스펙션)

사내 보안 장비는 HTTPS 통신을 가로채 자기 인증서로 재서명해 넘겨준다. 여기서 파이썬은
**두 군데서 막힐 수 있고, 둘을 같이 풀어야 한다.**

| 막히는 지점 | 나타나는 에러 | 처리 |
|---|---|---|
| 회사 인증서를 신뢰하지 않음 | `unable to get local issuer certificate` | `ssl.create_default_context()` 를 쓴다. 윈도우에서는 윈도우 인증서 저장소(ROOT/CA)를 함께 읽으므로 회사 인증서가 잡힌다. **`certifi` 를 지정하면 안 된다** — 그 순간 윈도우 저장소를 덮어써서 이 에러로 되돌아간다 |
| 재서명 인증서에 AKI 확장이 없음 | `Missing Authority Key Identifier` | 3.13부터 기본으로 켜지는 `VERIFY_X509_STRICT` 플래그만 해제한다 ([cpython#138193](https://github.com/python/cpython/issues/138193)) |

`main.py` 의 `_make_ssl_context()` 가 이 둘을 함께 처리하고, 모든 외부 통신이 그 설정을
쓰는 하나의 세션(`SESSION`)을 지난다. `verify_mode` 와 `check_hostname` 은 건드리지 않으므로
**인증서 검증 자체는 그대로 켜져 있다.** `truststore` 가 설치되어 있으면 검증을 OS에 맡겨
더 깔끔하게 해결된다(`requirements.txt` 에 포함).

> `feedparser` 에 URL을 직접 넘기면 feedparser가 자체적으로 접속해 이 설정을 타지 못하고,
> 실패해도 예외 없이 빈 결과를 준다. 그래서 받아오는 것은 `SESSION` 이 하고 feedparser에는
> 받아온 내용만 넘긴다.

프로그램 창이 뜨면 위쪽 칸에 키워드·회사 이름·메일 받는 사람·발급받은 DART 인증키를
직접 입력한다. 회사 이름은 `삼성` 처럼 짧게 넣으면 삼성전자·삼성물산이 모두 걸린다.
한 번 입력해두면 창을 닫았다 다시 열어도 그대로 남아 있다(같은 폴더의 `settings.json`에
자동 저장된다). 그다음 "뉴스 수집하기" · "DART 수집하기" 버튼으로 하나씩 확인해보고,
결과가 마음에 들면 "메일 보내기"나 "전체 실행"을 누른다.

**결과창과 메일은 출처별로 나눠서 보여준다.** 버튼을 누르면 방금 그 버튼이 가져온 것만
나오고(앞서 모은 것과 섞이지 않는다), 그 아래에 `뉴스 47건 · DART 10건` 처럼 출처별
요약이 한 줄 붙는다. 메일 본문도 뉴스 섹션과 공시 섹션으로 나뉜다. 한 목록에 시간순으로
섞으면 읽기 어렵고, 특히 **공시는 접수 날짜만 알 수 있어서**(시각 정보가 없다) 같은 날
뉴스보다 늘 아래로 밀려 뒤죽박죽으로 보인다. 시각을 모르는 항목은 `00:00` 대신 날짜만
표시한다.

## 3. 자주 나는 에러

| 증상 | 원인과 해결 |
|---|---|
| `클래식 아웃룩 자동 발송이 안 됩니다` | 새 아웃룩만 설치된 경우 정상적으로 뜨는 메시지다. 자동으로 메일 창을 열어주니 [보내기]만 누르면 된다 |
| 그래도 메일 창이 안 뜬다 | 아웃룩이 꺼져 있거나 로그인이 안 된 경우가 대부분. 아웃룩을 먼저 켜서 로그인 화면이 없는지 확인 |
| `pywin32 가 설치되어 있지 않습니다` | `pip install pywin32` 를 실행한다. 사전 준비에서 이미 깔았다면 다른 파이썬 버전에 깔린 것일 수 있다 — 프로그램을 실행하는 것과 같은 파이썬으로 깔아야 한다 (`py -3.13 -m pip install pywin32` 처럼 버전을 지정) |
| `아웃룩 발송은 윈도우에서만 됩니다` | 맥/리눅스에서 실제 발송을 시도한 경우. 발송은 윈도우 PC에서 |
| `CERTIFICATE_VERIFY_FAILED ... Missing Authority Key Identifier` | 위 「사내망 대응」 참고. `main.py` 는 이미 처리하고 있으니, 실습 중 직접 만든 코드에서 났다면 STEP 2 의 "막히면" 안내를 따른다 |
| `unable to get local issuer certificate` | 같은 문제의 다른 얼굴이다. 위 「사내망 대응」 표를 참고 — `certifi` 를 지정해서 윈도우 인증서 저장소를 덮어쓴 경우가 대부분이다 |
| 뉴스 수집이 전부 `검색 실패` | 회사 네트워크가 `news.google.com` 을 막는 경우가 가장 흔하다. `python 한국뉴스_점검.py` 를 실행하면 구글이 막힌 건지 네트워크 전체가 막힌 건지 구분해서 알려준다. 구글만 막혔으면 보너스 실습의 언론사 RSS로 대체한다 |
| 뉴스 수집이 `0건` (실패는 아님) | 요청은 정상인데 그 키워드로 걸리는 기사가 없는 경우다. 키워드를 더 넓은 단어로 바꿔서 시험해본다 |
| DART 가 `0건` 인데 이유를 모르겠다 | `python dart_점검.py` 를 실행한다 (파일을 열어 인증키와 회사명을 먼저 채울 것). 기간을 1일/3일/7일로 늘려가며 각각 몇 건이 잡히는지 보여주므로, "그 회사가 그날 공시를 안 한 것"인지 "이름을 잘못 적은 것"인지 바로 구분된다 |
| DART 가 `0건` — 하루치만 조회했다 | **특정 회사는 매일 공시하지 않는다.** 하루치 + 회사 필터면 0건이 오히려 정상이다. `DAYS_BACK` 이 기본 7일로 되어 있는 이유다 |
| DART 가 `0건` — 회사 이름이 안 맞는다 | DART 목록 조회는 **회사 이름으로 검색할 수 없어서** 기간 전체를 받아 직접 걸러낸다. 필터는 부분 일치라 `삼성` 이면 삼성전자·삼성물산이 모두 걸린다. 반대로 정식 명칭과 다른 약칭(예: `현대차` → 실제로는 `현대자동차`)은 안 걸릴 수 있다 |
| DART `[013]` | 오류가 아니다. 그 기간에 공시가 없다는 뜻 (주말·공휴일이면 정상) |
| DART `[020]` | 하루 호출 한도 초과. 내일 다시 |

막히면 **에러 메시지 전문을 그대로 복사해서 Claude에게 붙여넣는 것**이 가장 빠르다.

## 4. 매일 자동으로 실행하기

교육에서는 수동 실행까지만 한다. 자동화는 이 단계를 추가하면 된다.

지금 만든 프로그램은 창을 띄워놓고 버튼을 직접 눌러야 동작하는 방식이라, 이 상태 그대로
예약 실행에 넣으면 화면만 뜨고 아무 버튼도 안 눌린 채 남아 있는다. 사람 손 없이 매일
자동으로 돌리려면, "전체 실행" 버튼을 누르는 것과 같은 동작을 창 없이도 하도록 AI에게
따로 요청해서 만들어야 한다(예약 프로그램이 그 방식으로 하루에 한 번 대신 실행해주는
식). 이 실습에서는 여기까지는 다루지 않는다.

> PC가 꺼져 있으면 실행되지 않는다. 24시간 돌리려면 서버가 필요하다.

## 5. 보안 — 꼭 지킬 것

- **`settings.json` 파일은 절대 공유하지 않는다.** 프로그램 창에 입력한 인증키가 그대로
  저장된 파일이라, 메신저·메일·깃허브에 올리는 순간 키가 유출된다
  (이 폴더의 `.gitignore` 가 이미 `settings.json` 을 제외하도록 되어 있다).
- 크롤링 대상은 **공개된 뉴스·공시·RSS만** 쓴다. 로그인이 필요한 사이트, 유료 콘텐츠,
  사내망 시스템은 대상으로 삼지 않는다.
- 사내 기밀·개인정보를 프롬프트에 넣지 않는다. 이 스크립트가 다루는 것은 전부 공개 정보다.

## 파일 구성

| 파일 | 내용 |
