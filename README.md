# 바이브 코딩 교육

AI에게 프롬프트로 지시해서 실제로 돌아가는 업무 도구를 만들어 보는 사내 실습 교육.

## 과정 목록

### 2시간 단기 — 이슈 리포트 봇 만들기

> [`news-report-bot/`](news-report-bot/) · 소요 120분 · 각자 PC 로컬 실행

키워드를 정해두면 **매일 아침 내 메일함으로 요약 리포트가 오는** 파이프라인을 직접 만든다.

```
DART 공시  ─┐
구글 뉴스   ─┼─→ 중복 제거 → 아웃룩 발송 → 내 메일함
```

수집 소스를 구글 뉴스 → DART 순으로 붙인다. 구글 뉴스는 인증키가 없어서 첫 성공을 가장
빨리 보고, DART에서 조건을 많이 넣어야 하는 실무형 API를 경험하게 된다. 하나가 막혀도
나머지로 완주할 수 있는 구조다. 시간이 남으면 **언론사 RSS를 추가로 붙여보는 보너스
실습**도 준비돼 있다.

**진행 순서 (120분)**

| 시간 | 내용 |
|---|---|
| 10분 | 오프닝 — 완성본이 메일을 보내는 장면 시연 |
| 10분 | 세팅 점검 — 발급받아 온 키를 손에 들고 준비 (입력은 실습 중 프로그램 창에서 한다) |
| 45분 | 실습 1 · 수집 (구글 뉴스 → DART) |
| 45분 | 실습 2 · 메일 발송 (가장 많이 막히는 구간) |
| 10분 | 마무리 — 팀별 확장, 시간 남으면 추가실습(언론사 RSS) |

**교육 전에 미리 준비할 것** — 당일에 발급받으면 2시간 중 40분이 날아간다.

- 파이썬 **3.12** 설치 — 아래 **설치 파일 하나 누르기**로 끝난다 (3.13 이상은 사내망에서 통신이 막힌다)
- DART 인증키 (뉴스는 인증키가 필요 없다)
- **아웃룩(클래식) 로그인 확인** — 사내망은 SMTP를 막아서, 로그인된 아웃룩 앱을 직접 조작해 보낸다 (윈도우 전용)
- 모니터링할 키워드 3개

자세한 발급 절차와 자주 나는 에러 대응은 [`news-report-bot/README.md`](news-report-bot/README.md) 참고.

**실습 안내 페이지** — 당일에는 [`DART 뉴스 크롤링 및 메일발송 프로그램 만들기.html`](DART%20뉴스%20크롤링%20및%20메일발송%20프로그램%20만들기.html) 파일 하나만 열어두면 된다.
저장소를 내려받은 뒤 **더블클릭하면 브라우저로 바로 열리는 순수 HTML 파일**이라, 인터넷이
없어도 보인다 (깃허브 화면에서 링크를 누르면 소스 코드로 보이니, 받아서 직접 열 것).
사전 준비 체크리스트부터 단계별 프롬프트·성공 기준·막혔을 때 볼 정답 코드까지 이 한 파일
안에 전부 있다. 코드는 여기 안 담겨 있고, 이 저장소의
[`news-report-bot/`](news-report-bot/)는 그 결과물이 어떻게 생겼는지 보여주는 완성본(정답)일 뿐이다.

## 설치 — 파일 하나만 누르면 끝

**버전은 3.12 로 고정한다.** python.org가 직접 배포하는 설치 파일을 바로 받는다.
(3.12.10 은 윈도우 설치 파일이 제공되는 마지막 3.12 버전이다. 이후 3.12.x 는 소스만 배포된다.)

- 윈도우: [파이썬 3.12.10 받기 (64비트)](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe)
- 맥: [파이썬 3.12.10 받기 (macOS)](https://www.python.org/ftp/python/3.12.10/python-3.12.10-macos11.pkg)
- 설치 첫 화면 맨 아래 **`Add python.exe to PATH` 를 반드시 체크**한 뒤 `Install Now`.

설치 파일 실행이 회사 정책에 막히면 공식 설치 관리자를 쓴다 —
[설치 관리자 받기 (.msix)](https://www.python.org/ftp/python/pymanager/python-manager-26.3.msix)
를 깔고 `py install 3.12`. 이 방식은 PATH가 자동으로 설정된다.

> **버전은 3.12 로 맞춘다 (3.13 이상 금지).** 사내망은 보안 장비가 HTTPS 통신을 중간에서
> 열어보고 자기 인증서로 다시 서명해 넘겨주는데(TLS 인스펙션), 그 인증서에 Authority Key
> Identifier 확장이 없다. 파이썬 3.13부터 `ssl.create_default_context()` 가
> `VERIFY_X509_STRICT` 를 기본으로 켜면서 이 확장을 요구하기 때문에, 3.13 이상에서는
> `CERTIFICATE_VERIFY_FAILED ... Missing Authority Key Identifier` 로 모든 외부 통신이
> 막힌다. 회사 CA를 신뢰 목록에 넣어도 이 검사에서 걸리므로 해결되지 않는다
> ([cpython#138193](https://github.com/python/cpython/issues/138193)). 3.12는 이 검사를
> 켜지 않아 브라우저와 동일하게 동작한다.

저장소를 통째로 내려받았다면(초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기) 폴더 안의
**`파이썬 설치.bat`**(맥은 **`파이썬 설치.command`**)을 더블클릭해도 된다. 3.12 를 찾아서
없으면 설치해준다 — 이미 3.13 이상이 깔려 있어도 지우지 않고 3.12 를 나란히 깔아준다.
1~2분 걸리고, 검은 창이 뜨고 글자가 올라가는 동안 **창을 닫지 말 것.**

> API 키·인증 정보는 파일을 미리 준비할 필요 없이, 실습 중에 만드는 프로그램 창의 입력
> 칸에 직접 입력한다. 라이브러리 설치(`pip install ...`)와 코드 작성도 여기서
> 하지 않는다 — 그건 실습 자체의 일부라서, [`DART 뉴스 크롤링 및 메일발송 프로그램 만들기.html`](DART%20뉴스%20크롤링%20및%20메일발송%20프로그램%20만들기.html)의 단계별 안내를
> 따라 직접 한다.

**막혔을 때**

| 증상 | 해결 |
|---|---|
| 설치 파일(.exe) 실행이나 `.msix` 앱 설치(사이드로딩)가 회사 정책에 막힌다 | 저장소를 통째로 내려받은 뒤 폴더 안의 **`파이썬 설치.bat`** 파일을 대신 더블클릭한다. winget 으로 3.12 를 설치하고, 그것도 안 되면 다운로드 페이지를 열어준다 |
| 이미 3.13 이상이 깔려 있다 | 지우지 않아도 된다. 3.12 를 나란히 깔고, 프로그램 실행 시 `py -3.12 main.py` 로 실행하면 된다 |
| `파이썬 설치.bat` 실행 중 `Windows 보안` — "파일을 복사할 수 없음 (인터넷 보안 설정으로 인해...)" | 브라우저로 받은 파일에 "인터넷에서 받음" 표시(Mark of the Web)가 붙어서 그렇다. 이 파일은 실행되자마자 스스로 이 표시를 지우게 되어 있어 대부분 자동으로 해결된다. 그래도 뜨면 파일 우클릭 → **속성** → 맨 아래 **차단 해제** 체크 → 확인 후 다시 실행. zip으로 받아도 압축을 풀면 표시가 그대로 옮겨가니 zip은 해결책이 아니다 |
| 창이 깜빡하고 바로 꺼진다 | 압축을 안 푼 채 ZIP 안에서 실행한 경우다. 압축을 먼저 풀 것 |
| 파란 경고창 `Windows의 PC 보호` | `추가 정보` → `실행` 을 누르면 된다 |
| 맥에서 파일이 안 열린다 | 터미널에서 `chmod +x "파이썬 설치.command"` 를 한 번 실행한 뒤 다시 더블클릭 |

설치가 다 끝났는지 확인하려면 명령 프롬프트에서 `py -3.12 --version` (맥은 `python3.12 --version`).
`Python 3.12.10` 이 나오면 된 것이다.

## 참고

각 과정 폴더의 코드는 **완성본**이다. 실습에서는 이걸 그대로 복사하는 게 아니라
프롬프트로 처음부터 만들어 가고, 막혔을 때 갈아탈 안전망으로 쓴다.

> **주의** — 프로그램 창에 입력한 값은 같은 폴더의 `settings.json` 파일에 자동 저장되고,
> 여기엔 API 키가 그대로 들어간다. 각 폴더의 `.gitignore` 가 이 파일을 제외하도록
> 되어 있으니, 그 설정을 지우지 말 것.
