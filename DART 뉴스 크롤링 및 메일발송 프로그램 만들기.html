실습 1 · 수집

STEP 0 · 프로젝트 뼈대 — 설정 읽어오기

5분

내 PC에 main.py 파일을 직접 만들고, .env에 적어둔 키워드·키를 코드에서 읽어오는 부분부터 시작한다. 여기서부터는 화면에 뭔가 찍히면 다음 단계로 넘어가도 된다.

여기서부터는 진짜로 코드를 짠다 — AI는 이렇게 쓴다

  1. 여기서 말하는 "AI"는 사내에서 쓰는 대화형 챗봇이다. 프롬프트를 넣으면 그에 맞는 파이썬 코드 파일(.py)을 다운로드할 수 있게 준다 — 이 페이지처럼 직접 실행해주지는 않고, 내 PC의 파일을 열어보거나 고쳐주지도 않는다.
  2. 아래 프롬프트를 복사해서 그 AI 채팅창에 그대로 붙여넣는다.
  3. AI가 내려주는 파일을 받아서, 내 PC의 news-report-bot/main.py 로 그대로 저장(덮어쓰기)한다.
  4. 다음 단계로 넘어갈 때도 같은 대화창에서 계속 이어서 물어봐야 한다. 새 대화를 시작하면 AI가 지금까지 짜준 코드를 기억하지 못한다. AI는 내 PC의 파일을 직접 열어보지 못하니, 매번 "지금까지 코드 전체를 다시 통째로 달라"고 요청해서 파일을 새로 받는 식으로 진행한다 (아래 프롬프트마다 이미 그렇게 요청하도록 되어 있다).
이 프롬프트를 AI에게 붙여넣기 
파이썬으로 DART·뉴스 정보 크롤링 및 메일발송 프로그램의 첫 부분을 작성해줘. 다음을 포함해야 해:

1. python-dotenv로 .env 파일을 읽어온다 (load_dotenv() 호출).
2. .env의 값을 쉼표로 구분해 리스트로 만드는 _env_list(name) 함수를 만들고,
   이걸로 KEYWORDS, RSS_FEEDS, DART_WATCH 를 만들어줘. 값이 없으면 빈 리스트.
3. DAYS_BACK(기본값 1), MAX_ITEMS(기본값 40)은 .env에서 정수로 읽어와줘.
4. DART_API_KEY, NEWSAPI_KEY 도 .env에서 읽어와줘.
5. MAIL_TO 는 쉼표로 구분된 받는 사람 리스트로 읽어와줘.
6. 수집한 기사/공시 하나를 표현하는 Item 이라는 dataclass를 만들어줘.
   필드: source(문자열), title, link, dt(datetime 또는 None, 기본 None), note(기본 빈 문자열).
   dt를 "MM/DD HH:MM" 형식(한국시간 KST = UTC+9)으로 보여주는 when 이라는 property도 추가해줘.
   dt가 없으면 "-" 를 리턴.
7. HTML 태그와 엔티티를 제거하는 clean_text(raw) 함수도 추가해줘
   (정규식으로 <...> 태그 제거한 뒤 html.unescape 적용).
8. 맨 아래에 KEYWORDS를 출력하는 코드를 넣어서 잘 읽히는지 확인할 수 있게 해줘.

지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 파일로 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • pip install python-dotenv 로 라이브러리를 먼저 설치했다
  • python main.py 를 실행하면 .env에 적은 키워드가 그대로 출력된다
  • Item(source="RSS", title="테스트", link="x") 를 만들어 item.when 을 출력하면 "-" 가 나온다

STEP 2 · 뉴스 검색 API — 헤더로 인증하기

10분

처음으로 인증 키가 필요한 API. 요청 헤더에 키를 실어 보내는 방식을 경험한다. (NewsAPI.org 무료 플랜은 개발/테스트용이라 호출 한도가 있고, 최근 한 달 기사만 검색된다)

터미널에 먼저 입력 pip install requests
이 프롬프트를 AI에게 붙여넣기 
NewsAPI.org로 기사를 모으는 collect_newsapi(page_size=10) 함수를 추가해줘.

- NEWSAPI_KEY 가 없으면 "- 뉴스 API 키가 없어 건너뜀 (.env의 NEWSAPI_KEY)" 을 출력하고 빈 리스트를 리턴한다.
- 있으면 KEYWORDS 각각에 대해 https://newsapi.org/v2/everything 에 GET 요청을 보낸다.
  - 헤더: X-Api-Key
  - 파라미터: q(키워드), language="ko", sortBy="publishedAt", pageSize
  - timeout=10
- requests.HTTPError 가 나면 "! 뉴스 API 검색 실패 ('키워드'): ..." 를 출력하고 그 키워드는 건너뛴다
  (401이면 키가 틀린 것, 429면 호출 한도 초과라는 뜻).
- requests.RequestException 이면 "! 뉴스 API 연결 실패: ..." 를 출력하고 건너뛴다.
- 응답 JSON의 articles 배열을 순회하면서, title은 clean_text로, link는 url을 쓴다.
  publishedAt("2024-01-01T00:00:00Z" 형식)은 datetime.fromisoformat으로 파싱한다
  (뒤의 Z는 "+00:00"으로 바꿔준 뒤 파싱). source는 "NewsAPI"로 Item을 만든다.

지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 파일로 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • pip install requests 를 실행했다 (RSS 단계에서 이미 깔았다면 생략)
  • .env에 뉴스 API 키를 비워두고 실행하면 에러 없이 "건너뜀" 메시지만 뜬다
  • 키를 채우고 실행하면 "NewsAPI 몇 건" 이 나온다 (0건이면 키워드를 영문/일반 단어로 바꿔서 시도)

STEP 3 · DART 공시 API — 실무형 API 경험

15분

파라미터가 가장 많은 API. 페이지네이션과 '결과 없음'을 에러와 구분하는 처리까지 다룬다.

이 프롬프트를 AI에게 붙여넣기 
전자공시(DART) 목록을 가져오는 collect_dart(max_pages=5) 함수를 추가해줘.

- DART_API_KEY 가 없으면 "- DART 키가 없어 건너뜀 (.env의 DART_API_KEY)" 출력 후 빈 리스트.
- 오늘 날짜(KST) 기준으로, DAYS_BACK 만큼 이전 날짜부터 오늘까지를 조회 범위로 잡는다.
- https://opendart.fss.or.kr/api/list.json 에 GET 요청:
  파라미터는 crtfc_key, bgn_de(YYYYMMDD), end_de(YYYYMMDD), page_no, page_count=100.
- 응답 JSON의 status 값에 따라:
  - "013" 이면 그 기간에 공시가 없다는 뜻이니 에러가 아니라 조용히 조회를 멈춘다.
  - "000" 이 아닌 다른 값이면 "! DART 응답 오류 [코드] 메시지" 를 출력하고 멈춘다.
- DART_WATCH 에 회사명이 지정돼 있으면 그 회사들만 남기고, 비어 있으면 전부 포함한다.
- 제목은 "[회사명] 보고서명" 형식, 링크는
  https://dart.fss.or.kr/dsaf001/main.do?rcpNo=접수번호, note에는 제출인(flr_nm)을 넣는다.
  rcept_dt(YYYYMMDD)를 KST 자정 기준 dt로 변환한다. source는 "DART".
- total_page 까지 페이지를 넘기며 반복하고, 다 돌면 멈춘다.
- requests.RequestException 이 나면 "! DART 연결 실패: ..." 출력 후 멈춘다.

지금까지의 요구사항을 모두 반영한 파이썬 코드 전체를 처음부터 끝까지 빠짐없이 담은 파일로 줘. 그 파일을 받아서 내 PC의 main.py로 그대로 저장(덮어쓰기)할 거야.

성공 기준

  • DART_API_KEY 를 채우고 실행하면 에러 없이 "DART 몇 건" 이 찍힌다 (주말·공휴일엔 0건이 정상)
  • [013] 이 콘솔에 에러처럼 빨갛게 뜨지 않고 조용히 지나간다
  • DART_WATCH 에 회사명을 넣으면 그 회사 공시만 남는다

이 프롬프트를 AI에게 붙여넣기

STEP 7 · 새 아웃룩 폴백 + 발송 함수 완성

10분

새 아웃룩(New Outlook)은 방금 만든 방식 자체를 지원하지 않는다. 그 경우를 감지해서 대신 처리해주는 안전망을 만든다.

이 프롬프트를 AI에게 붙여넣기 
새 아웃룩에서도 쓸 수 있도록 폴백과, 둘을 합치는 최종 발송 함수를 추가해줘.

1. _open_draft_mail(subject, plain_body) 함수:
   - 제목·받는사람·본문이 채워진 새 메일 작성 창을 mailto: 링크로 열어준다
     (webbrowser.open 사용). 사람이 [보내기]만 누르면 되는 방식이다.
   - mailto 는 길이 제한이 있으니 본문은 앞 1500자까지만 담고, 넘치면
     "(내용이 길어 일부만 담았습니다...)" 안내를 덧붙인다.
   - 받는사람은 콤마로 이어붙인 뒤 URL 인코딩한다.

2. send_mail(subject, html_body, plain_body) 함수:
   - MAIL_TO 가 비어 있으면 "! 받는 사람이 없습니다" 출력 후 종료.
   - sys.platform 이 "win32" 가 아니면 "! 아웃룩 발송은 윈도우에서만 됩니다" 출력 후 종료.
   - win32com.client 를 import 시도. ImportError 면 pywin32 설치 안내 후 종료.
   - _send_via_classic_outlook 을 시도한다. 성공하면 "✓ 메일 발송 완료 (클래식 아웃룩, 자동 발송)"
     을 출력하고 끝낸다.
   - 예외가 나면(새 아웃룩인 경우) "! 클래식 아웃룩 자동 발송이 안 됩니다: ..." 와
     "새 아웃룩은 자동화를 지원하지 않습니다" 를 출력한 뒤, _open_draft_mail 로 넘어가서
     초안을 열어주고 "✓ 메일 초안 열기 완료 (수동 발송 필요)" 를 출력한다.

  • 새 아웃룩만 있는 PC에서는 예외 메시지가 뜨고, 내용이 채워진 메일 창이 자동으로 뜬다
  • MAIL_TO 를 비워두고 실행하면 에러 없이 안내 메시지만 출력된다

STEP 9 · RSS 수집 추가하기 (보너스)

시간이 남으면 해보는 추가 실습. 구글 뉴스는 키워드 검색 결과를 RSS로 내준다 — API 키 없이 돌아가는 소스를 하나 더 붙여본다. 연합뉴스·한국경제·매일경제처럼 특정 언론사만 보고 싶으면 .env의 RSS_FEEDS에 그 언론사 RSS 주소를 추가하면 된다.

터미널에 먼저 입력 pip install feedparser
이 프롬프트를 AI에게 붙여넣기 
지금 완성된 프로그램에 RSS 수집 기능을 추가로 붙여줘.

1. google_news_rss(keyword) 함수: 아래 형태의 URL 문자열을 리턴해줘 (keyword는 URL 인코딩).
   https://news.google.com/rss/search?q={keyword}&hl=ko&gl=KR&ceid=KR:ko

2. collect_rss(limit_per_feed=10) 함수:
   - RSS_FEEDS 목록 + KEYWORDS 각각으로 만든 구글뉴스 RSS 주소들을 모두 대상으로 한다.
   - feedparser로 각 주소를 읽는다. feedparser는 네트워크가 막혀도 예외를 던지지 않고
     조용히 빈 결과를 주니까, parsed.bozo 이면서 entries가 비어 있으면
     "! RSS 실패 (...)" 를 출력하고 그 피드는 건너뛴다.
   - 각 피드에서 최대 limit_per_feed개까지만 가져온다.
   - title은 clean_text로 정리하고, link, 발행시각(entry.published_parsed가 있으면
     UTC datetime으로 변환)을 채워서 Item으로 만든다. source는 "RSS".
   - 모은 Item 리스트를 리턴한다.

3. main() 함수의 수집 목록 맨 앞에 ("RSS", collect_rss) 를 추가해서, RSS → 뉴스 API → DART
