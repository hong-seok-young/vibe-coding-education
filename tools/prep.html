RSS, API 란?

RSS 란

사이트가 새 글 목록을 엑셀 표처럼 정리해서 공개해둔 것이다. 홈페이지는 사람이 보라고 꾸민 PDF 보고서 같아서 프로그램이 거기서 제목만 골라내기 어렵다. RSS 는 같은 내용을 제목 · 링크 · 날짜 칸으로 나눠둔 표라서 프로그램이 바로 읽는다.

인증키가 필요 없는 이유 — 가게 앞에 「가져가세요」 하고 내놓은 무료 신문 같은 것이라, 누가 가져가는지 확인하지 않는다. 구글 뉴스는 검색 결과까지 이렇게 내놔서 인증키 없이 검색어로 찾을 수 있다.
API 란

홈페이지는 사람이 보라고, API 는 프로그램이 받아가라고 열어둔 창구다. 「이 회사 · 이 기간 공시 줘」 처럼 조건을 넣어 요청하면 답을 준다.

인증키는 출입증 — 누가 얼마나 쓰는지 세려고 발급한다. 남에게 주지 않는다.
RSS vs API
RSS 프로그램 목록을 그냥 가져감 공개된 목록누구나
API 프로그램 요청 · 조건 + 인증키 답 창구확인 후 답
RSSAPI
방식공개된 목록을 그냥 받음조건을 넣어 요청하면 답을 줌
인증키거의 없음대부분 필요
검색사이트마다 다름 (구글 뉴스는 검색어 가능, 언론사 RSS 는 정해진 목록만)검색어·날짜 등 조건 지정 가능
양한 번에 정해진 만큼만나눠서 끝까지 받을 수 있음
예구글 뉴스, 연합뉴스·한국경제 RSSDART, 네이버 검색 API
구글 뉴스 RSS 는 한 번에 약 100개

다음 페이지가 없어서 그 이상은 못 받는다.

  • 기간을 따로 정하지 않으면 → 최근 100개. 기사가 많은 회사는 며칠치, 적은 회사는 몇 달치
  • 기간을 정하면 → 그 기간 안에서 최근 100개. 검색어 뒤에 after:2023-09-01 before:2023-09-30 처럼 붙인다
API 한도 세는 법

요청 한 번 = 택배 상자 하나. 한도는 상자 개수로 센다 — 상자 안에 기사가 몇 건 들었는지는 상관없다.

삼성전자기사 10건 현대차기사 10건 LG화학기사 10건 상자 3개 = 요청 3회기사는 30건
DART 1공시 100건 DART 2공시 100건 · · · DART 30공시 100건 상자 30개 = 요청 30회공시는 약 3,000건

하루 한도는 네이버 2만 5천 회, DART 2만 회 — 실습처럼 하루 몇 번 돌리는 정도로는 닿지 않는다.
다른 뉴스 소스
  • 구글 뉴스 — 인증키 없음. 오늘 실습에서 쓰는 것
  • 언론사 RSS (연합뉴스·한국경제) — 인증키 없음. 그 언론사 최신 기사를 통째로 받는다. 검색어로 찾기는 안 된다
  • 네이버 검색 API — 무료 인증키, 요청 하루 2만 5천 회 · 월 77만 5천 회. 네이버 클라우드 계정이 필요하다. NAVER API HUB
