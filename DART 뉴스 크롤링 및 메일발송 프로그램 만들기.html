실습 1 · 수집

STEP 0 · 프로그램 창 만들기

10분

터미널 대신 더블클릭하면 뜨는 진짜 프로그램 창을 만든다. 여기서부터는 창이 뜨면 다음 단계로 넘어가도 된다.

여기서부터는 진짜로 코드를 짠다 — AI는 이렇게 쓴다

  1. 여기서 말하는 "AI"는 사내에서 쓰는 대화형 챗봇이다. 프롬프트를 넣으면 그에 맞는 파이썬 코드 파일(.py)을 다운로드할 수 있게 준다 — 이 페이지처럼 직접 실행해주지는 않고, 내 PC의 파일을 열어보거나 고쳐주지도 않는다.
  2. 아래 프롬프트를 복사해서 그 AI 채팅창에 그대로 붙여넣는다.
  3. AI가 내려주는 파일을 받는다. 지금은 이 단계가 처음이라 내 PC에 아무 파일도 없다 — 실습용 폴더를 하나 정해두고(바탕화면에 새로 만들어도 된다) 받은 파일을 그 안으로 옮겨둔다. 어디에 어떤 이름으로 저장하고 어떻게 실행하는지는 AI가 알려주니 그대로 따라 하면 된다.
  4. 다음 단계부터는 매번 파일을 새로 받는다. AI는 파일을 내려주기만 하니, 같은 이름으로 또 받으면 브라우저가 main (2).py, main (3).py 처럼 뒤에 번호를 붙여 저장한다. 이름을 맞추려고 애쓸 필요 없다 — 방금 받은 가장 최신 파일을 실행하면 된다. 단 폴더는 처음 정한 그대로 계속 쓴다 — 창에 입력해둔 인증키 같은 값이 프로그램 파일과 같은 폴더에 저장되기 때문에, 폴더를 옮겨 다니면 매번 처음부터 다시 입력해야 한다.
  5. 다음 단계로 넘어갈 때도 같은 대화창에서 계속 이어서 물어봐야 한다. 새 대화를 시작하면 AI가 지금까지 짜준 코드를 기억하지 못한다. AI는 내 PC의 파일을 직접 열어보지 못하니, 매번 "지금까지 코드 전체를 다시 통째로 달라"고 요청해서 파일을 새로 받는 식으로 진행한다 (아래 프롬프트마다 이미 그렇게 요청하도록 되어 있다).
  6. 이 AI 툴은 질문마다 답하는 모델이 자동으로 바뀐다("스마트 라우팅"). 어떤 모델은 파일을 바로 첨부해주고, 어떤 모델은 파일 대신 채팅창에 코드를 텍스트로 그대로 보여준다. 파일 첨부 대신 텍스트로 나오면, 화면 위쪽에서 모델을 Gemini로 바꾼 뒤 같은 프롬프트를 다시 넣어본다 — 그래도 안 되면 이 페이지의 "정답 코드 파일 받기" 버튼을 대신 쓴다.
이 프롬프트를 AI에게 붙여넣기 
파이썬으로 DART·뉴스 정보 크롤링 및 메일발송 프로그램을 만들 건데, 터미널 창이
아니라 더블클릭하면 뜨는 진짜 프로그램 창(화면)으로 만들어줘. 나는 프로그래밍을 전혀
몰라 — 기술 용어 없이, 아래 내용대로만 동작하게 만들어주면 돼.

창을 열면 위쪽에 이런 칸들이 보이면 좋겠어 — 살펴보고 싶은 키워드들(여러 개), 지켜보고
싶은 회사 이름(있으면), 메일 받을 사람, 그리고 아까 발급받은 DART 인증키를 직접 입력할 수
있는 칸들. 여기 입력한 값은 창을 닫았다가 다시 열어도 그대로 남아있게 저장해줘.

그 아래엔 "뉴스 수집하기", "DART 수집하기", "메일 보내기" 버튼 세 개를 만들어주고, 맨
아래엔 지금까지 무슨 일이 있었는지 볼 수 있는 넓은 결과창을 만들어줘. 지금 단계에서는
버튼을 눌러도 아직 실제로 아무 일도 안 해도 돼 — 나중에 하나씩 실제로 동작하게 만들
거야. 지금은 버튼을 누르면 결과창에 짧은 안내만 나오면 충분해.

그리고 나중에 모을 뉴스 기사나 공시들을 하나하나 깔끔하게 정리해서 다룰 수 있는 방법도
만들어줘. 항목마다 어디서 가져온 건지, 제목, 원문으로 가는 링크, 언제 올라온 건지(아직
모르면 비워둬도 됨), 참고할 만한 짧은 메모(없으면 빈칸)를 담고 있어야 해. 날짜는 "09/03
14:30"처럼 한국 시간 기준으로 보기 편하게 보여주고, 모르면 그냥 "-"라고 보여주면 돼.

그리고 창이 열리면 결과창 맨 처음에 지금 몇 점 몇 버전의 파이썬으로 돌고 있는지 한 줄로
보여줘. 나중에 문제가 생겼을 때 알려주기 편하게.

채팅창에 코드를 텍스트로 보여주지 말고, 위 내용을 전부 반영한 파이썬 코드 전체를 담은 다운로드 가능한 파일(.py)로 첨부해서 줘. 나는 지금 내 PC에 파이썬만 깔아둔 상태고 이 프로그램 파일은 아직 하나도 없어. 그러니 받은 파일을 어디에 어떤 이름으로 저장하고 어떻게 실행하면 창이 뜨는지, 처음 하는 사람 기준으로 순서대로 알려줘.

그리고 파일을 만들 때 글자 속에 줄바꿈 기호(백슬래시 다음에 n)를 넣지 말아줘. 받은 파일에서 그 백슬래시가 사라져 프로그램이 아예 안 열린 적이 있어. 줄바꿈이 필요하면 chr(10) 을 쓰고, 결과창에 빈 줄을 넣고 싶으면 빈 글자를 한 번 더 찍으면 된다고 들었어.

성공 기준

  • 받은 파일을 AI가 알려준 대로 저장하고 실행하면, 검은 터미널 창이 아니라 진짜 프로그램 창이 뜬다
  • 결과창 맨 위에 실행 중인 파이썬 버전이 한 줄 표시된다
  • 입력 칸에 아무 값이나 써넣고 창을 닫았다가 다시 열면, 써넣은 값이 그대로 남아있다
  • 버튼 세 개를 눌러보면 에러 없이 결과창에 뭔가 나온다

STEP 2 · 뉴스 수집 버튼 연결하기

10분

'뉴스 수집하기' 버튼을 누르면 실제로 구글 뉴스에서 키워드에 걸리는 기사를 가져오게 만든다. 인증키가 필요 없고 호출 한도도 없어서, 첫 성공을 가장 빨리 볼 수 있는 방식이다.

터미널에 먼저 입력 — 사전 준비에서 이미 받아뒀으면 넘어가기 pip install feedparser
이 프롬프트를 AI에게 붙여넣기 
이제 "뉴스 수집하기" 버튼을 눌렀을 때, 구글 뉴스에서 실제로 기사를 가져오도록
만들어줘.

구글 뉴스는 어떤 키워드로 검색한 결과를, 인증키나 가입 없이도 프로그램이 그대로 받아올 수
있는 형태로 내준다. 아까 입력해둔 키워드들 하나하나로 그렇게 검색해서 관련 기사를
가져와줘. 한국어 기사가 나오게 한국 기준으로 검색하면 돼.

키워드 칸이 비어있으면 결과창에 "키워드가 없어 건너뜀"이라고 알려주고 그냥 끝내면 돼.

기사를 못 가져오는 경우도 있는데, 이때 그냥 조용히 0건으로 넘어가면 내가 원인을 알 수가
없어. 그러니 "회사 네트워크가 막아서 아예 못 받아온 경우"와 "정상적으로 받아왔는데 그
키워드로 걸리는 기사가 없는 경우"를 구분해서, 각각 무슨 상황인지 결과창에 알려줘. 그리고
그 키워드는 넘어가서 다음 키워드로 계속 진행해줘.

가져온 기사들도 아까 만든 정리된 형태로 하나씩 담아서 지금까지 모은 목록에 합쳐줘 —
제목, 링크는 원문 주소로, 발행 날짜/시간도 같이 넣고, 어디서 가져왔는지는 "뉴스"라고
표시해줘. 그리고 몇 건을 새로 가져왔는지, 지금까지 모은 항목들의 제목을 최신순으로
결과창에 보여줘.

버튼을 누르는 동안 창이 멈춘 것처럼 보이지 않게, 실제 작업은 뒤에서 진행되게 해줘.

마지막으로 우리 회사 사정을 하나 알려줄게. 회사 보안 장비가 인터넷 통신을 중간에서
열어보고 자기 인증서로 다시 서명해서 넘겨주는 환경이야(TLS 인스펙션). 브라우저에서는 아무
문제 없는데, 파이썬 3.13 부터는 인증서를 검사할 때 그 회사 인증서에 없는 항목까지
요구하는 엄격 검사가 기본으로 켜져 있어서, 통신을 아예 거부하고
CERTIFICATE_VERIFY_FAILED ... Missing Authority Key Identifier 에러를 낸다고 들었어.

그러니 인터넷에서 뭘 받아오는 부분은 처음부터 이 환경에서도 되게 만들어줘. 정확히 이 두
가지를 같이 해줘야 한다고 들었어.

1. SSL 설정은 ssl.create_default_context() 로 만들어줘. 윈도우가 이미 신뢰하는 인증서
   목록(회사 인증서가 여기 들어있다)을 같이 읽어주는 게 이거야. certifi 같은 걸 따로
   지정하면 오히려 이 목록을 덮어써서 회사 인증서를 못 믿게 되니까 지정하지 말아줘.
2. 그 설정에서 엄격 검사 플래그만 빼줘. verify_flags 에서 VERIFY_X509_STRICT 를 빼는 것
   (ctx.verify_flags &= ~ssl.VERIFY_X509_STRICT) 이 정확히 필요한 조치야.

한 가지 미리 말해둘게. ctx.options 쪽 플래그(OP_LEGACY_SERVER_CONNECT 같은 것)를 켜는 건
이 에러와 아무 상관이 없어서 Missing Authority Key Identifier 가 그대로 남아. 그쪽은
건드리지 말아줘. 그리고 안전은 지키고 싶으니까 인증서 검사 자체를 끄는 방식
(verify_mode 나 check_hostname 을 끄는 것)도 쓰지 말아줘.

채팅창에 코드를 텍스트로 보여주지 말고, 앞에서 만들어준 것에 지금 말한 걸 더해서 처음부터 끝까지 빠짐없이 담은 전체를 다운로드 가능한 파일(.py) 하나로 다시 첨부해서 줘. 앞 단계까지 되던 기능은 하나도 빼지 말고 그대로 두고, 바뀐 부분만 잘라서 주지 말고 항상 전체를 통째로 줘.

그리고 파일을 만들 때 글자 속에 줄바꿈 기호(백슬래시 다음에 n)를 넣지 말아줘. 받은 파일에서 그 백슬래시가 사라져 프로그램이 아예 안 열린 적이 있어. 줄바꿈이 필요하면 chr(10) 을 쓰고, 결과창에 빈 줄을 넣고 싶으면 빈 글자를 한 번 더 찍으면 된다고 들었어.

성공 기준

  • pip install feedparser 를 실행했다
  • 키워드 칸을 비워두고 버튼을 누르면 에러 없이 "건너뜀" 메시지만 뜬다
  • 키워드를 채우고 버튼을 누르면 결과창에 한국어 기사 제목들이 나온다
  • 버튼을 누른 동안에도 창이 멈추지 않고 계속 움직인다
그래도 결과창에 CERTIFICATE 어쩌고 하는 에러가 뜨면

회사 보안 장비 때문에 생기는 문제다. 위 프롬프트에 이미 대응을 요청해뒀지만, AI가 빠뜨렸거나 엉뚱한 설정을 건드릴 수 있다. 에러 문장에 Missing Authority Key Identifier 가 보이면 최신 파이썬의 엄격 검사에 걸린 것이고, unable to get local issuer certificate 가 보이면 회사 인증서를 아직 못 믿고 있는 것이다. 아래 프롬프트를 이어서 넣으면 된다 — 고쳐야 할 곳을 콕 집어 알려주는 내용이라, 애매하게 물어보는 것보다 훨씬 잘 듣는다. 그래도 안 되면 에러 문장을 그대로 복사해서 AI에게 붙여넣는 게 가장 빠르다.

이 프롬프트를 이어서 넣기 
뉴스 수집하기 버튼을 눌렀더니 결과창에 CERTIFICATE 어쩌고 하는 에러가 떴어.
(에러 문장을 여기에 그대로 붙여넣기)

우리 회사는 보안 장비가 인터넷 통신을 중간에서 열어보고 자기 표식을 붙여서 넘겨주는
환경이야. 브라우저에서는 잘 되는데 이 프로그램만 막혀.

인터넷에서 뭘 받아오는 부분을 이 환경에서도 되게 고쳐줘. 두 가지를 같이 해줘야 한다고
들었어. 둘 중 하나만 하면 다른 에러로 바뀐다고 해.

1. SSL 설정은 ssl.create_default_context() 로 만들어줘. 윈도우가 이미 신뢰하는 인증서
   목록(회사 인증서가 여기 들어있다)을 같이 읽어주는 게 이거야. certifi 를 따로 지정하면
   오히려 이 목록을 덮어써서 unable to get local issuer certificate 로 바뀐다고 하니까
   지정하지 말아줘.
2. 그 설정에서 엄격 검사 플래그만 빼줘. verify_flags 에서 VERIFY_X509_STRICT 를 빼는 것
   (ctx.verify_flags &= ~ssl.VERIFY_X509_STRICT) 이 정확히 필요한 조치야.

ctx.options 쪽 플래그(OP_LEGACY_SERVER_CONNECT 같은 것)를 켜는 건 이 에러와 아무 상관이
없어서 Missing Authority Key Identifier 가 그대로 남아. 이미 그렇게 되어 있으면 지워줘.
설치해야 할 게 있으면 그것도 알려줘.

안전은 그대로 지키고 싶어. 인증서 검사 자체를 끄는 방식(verify_mode 나 check_hostname 을
끄는 것)은 쓰지 말아줘.

15분

'DART 수집하기' 버튼을 누르면 실제로 전자공시시스템에서 공시를 가져오게 만든다. 조건을 가장 많이 넣어서 요청해야 하는 서비스다.

터미널에 먼저 입력 — 사전 준비에서 이미 받아뒀으면 넘어가기 pip install requests
이 프롬프트를 AI에게 붙여넣기 
이번엔 "DART 수집하기" 버튼을 눌렀을 때, 전자공시시스템(DART)이라는 곳에서 실제로
공시 목록을 가져오도록 만들어줘.

DART 인증키가 없으면 결과창에 "DART 인증키가 없어 건너뜀"이라고 알려주고 넘어가.

키가 있으면, 최근 일주일치 공시 목록을 DART에 물어봐서 가져와줘. 지켜보고 싶은 회사
이름을 입력해뒀으면 그 회사들 것만 남기고, 안 적었으면 전체 다 가져와줘. 회사 이름은
정확히 같지 않아도 그 글자가 들어가면 걸리게 해줘 — "삼성"이라고 적으면 삼성전자,
삼성물산 같은 것들이 다 걸리게.

여기서 중요한 게 하나 있어. DART는 회사 이름으로 찾아달라고 요청할 수가 없어서, 그
기간의 공시를 전부 받아온 다음에 우리가 직접 골라내야 해. 그래서 받아오는 걸 중간에
끊으면 안 돼 — 뒷부분에 그 회사 공시가 있었는데 못 보고 "없다"고 할 수 있으니까,
그 기간 것을 끝까지 다 받아온 다음에 골라내줘.

가져온 공시 하나하나도 아까 만든 정리된 형태로 담아서 지금까지 모은 목록에 합쳐줘 —
제목은 "[회사명] 보고서 이름" 형식으로, 링크는 그 공시 원문을 볼 수 있는 주소로, 날짜는
접수된 날짜, 메모에는 누가 제출했는지 넣어줘. 어디서 가져왔는지는 "DART"라고 표시하고.

그리고 결과가 0건일 때가 문제야. 그냥 "0건"만 뜨면 내가 뭘 잘못했는지 알 수가 없어.
0건이 나오는 이유가 여러 가지잖아 — 그 기간에 공시가 아예 없는 경우(주말이나 공휴일엔
흔한 일이야), 공시는 많았는데 그중에 그 회사 것이 없는 경우, 인증키에 문제가 있는 경우.
이 셋을 구분해서 결과창에 알려줘. 특히 두 번째 경우엔 "공시 몇 건을 살펴봤는데 그중
그 회사 건 없었다"처럼 살펴본 전체 건수도 같이 보여줘. 그러면 회사 이름을 잘못 적은
건지, 기간을 늘려야 하는 건지 내가 판단할 수 있어.

몇 건을 새로 가져왔는지, 지금까지 모은 항목들의 제목을 최신순으로 결과창에 보여주고,
이 버튼도 누르는 동안 창이 멈춘 것처럼 보이지 않게 해줘.

채팅창에 코드를 텍스트로 보여주지 말고, 앞에서 만들어준 것에 지금 말한 걸 더해서 처음부터 끝까지 빠짐없이 담은 전체를 다운로드 가능한 파일(.py) 하나로 다시 첨부해서 줘. 앞 단계까지 되던 기능은 하나도 빼지 말고 그대로 두고, 바뀐 부분만 잘라서 주지 말고 항상 전체를 통째로 줘.

그리고 파일을 만들 때 글자 속에 줄바꿈 기호(백슬래시 다음에 n)를 넣지 말아줘. 받은 파일에서 그 백슬래시가 사라져 프로그램이 아예 안 열린 적이 있어. 줄바꿈이 필요하면 chr(10) 을 쓰고, 결과창에 빈 줄을 넣고 싶으면 빈 글자를 한 번 더 찍으면 된다고 들었어.

먼저 이것부터 — 에러 문장을 그대로 AI에게 붙여넣기

아래를 다 읽을 필요 없다. 결과창이나 검은 창에 나온 문장을 통째로 복사해서 AI 채팅창에 붙여넣고 "이거 왜 이래?"라고 물어보는 것이 가장 빠르다. 아래는 그렇게 해도 안 풀릴 때, 혹은 강사가 원인을 빨리 짚어야 할 때 보는 목록이다.

수집이 안 될 때

  • 결과창에 CERTIFICATE / Missing Authority Key Identifier — 회사 보안 장비가 인터넷 통신을 열어보고 자기 인증서로 다시 서명해 넘겨주는데, 파이썬 3.13 부터 기본으로 켜진 엄격 검사가 그 인증서에 없는 항목을 요구해 거부하는 것이다. 브라우저는 잘 되는데 프로그램만 막히는 이유다. STEP 2 의 "막히면" 안내를 펼쳐서 프롬프트를 이어 넣는다. AI가 자주 틀리는 지점 — 고쳐야 하는 건 verify_flags 에서 VERIFY_X509_STRICT 를 빼는 것 하나다. AI가 ctx.options |= ssl.OP_LEGACY_SERVER_CONNECT 같은 걸 넣어놨으면 그건 이 에러와 무관해서 아무 효과가 없다(실제로 이렇게 만들어 온 사례가 있다). 코드에 OP_LEGACY 가 보이면 그 줄을 짚어서 다시 시키면 된다. 인증서 검사를 아예 끄는 방식은 쓰지 않는다.
  • 뉴스가 전부 검색 실패 — 회사가 구글 뉴스를 막았을 수 있다. 한국뉴스_점검.py 를 실행하면 구글만 막힌 건지 네트워크 전체가 막힌 건지 구분해준다. 구글만 막혔으면 STEP 9(언론사 RSS) 로 대체한다.
  • 뉴스가 0건 (실패는 아님) — 그 키워드로 걸리는 기사가 없는 것이다. 더 넓은 단어로 바꿔본다.
  • DART 가 0건 — 이유가 세 가지다. ① 그 기간에 공시가 아예 없다(주말·공휴일이면 정상) ② 공시는 많았지만 그 회사 것이 없다 ③ 인증키 문제. 프로그램이 이 셋을 구분해 알려주게 만들어 두었으니 결과창 문장을 먼저 읽는다. dart_점검.py 를 실행하면 기간을 1일/3일/7일로 늘려가며 각각 몇 건인지 보여준다.
  • DART 에서 회사가 안 걸린다 — 이름은 짧게 넣는다. 삼성 이면 삼성전자·삼성물산이 다 걸리지만, 현대차 는 정식 명칭(현대자동차)과 달라서 안 걸린다.

메일이 안 갈 때

  • 클래식 아웃룩 자동 발송이 안 됩니다 — "새 아웃룩"만 깔린 PC에서 정상적으로 뜨는 메시지다. 오류가 아니다. 프로그램이 대신 메일 창을 열어주니 [보내기]만 누르면 된다.
  • 메일 창도 안 뜬다 — 아웃룩이 꺼져 있거나 로그인이 안 된 경우가 대부분이다. 아웃룩을 먼저 켜서 로그인 화면이 없는지 확인한다.
  • pywin32 가 설치되어 있지 않습니다 — 사전 준비의 설치 파일을 안 돌렸거나, 다른 파이썬 버전에 깔린 경우다. 여러 버전이 깔린 PC에서 흔하다. 사전 준비의 파이썬 설치.bat 을 다시 더블클릭하면 된다.
  • 받는 사람이 없다고 나온다 — 창의 "메일 받을 사람" 칸이 비어 있다.

AI 쪽에서 막힐 때

  • 프로그램 창이 아예 안 뜨고 검은 창만 깜빡한다 / SyntaxError: unterminated string literal — AI가 준 파일이 깨진 것이다. 파이썬에서 줄바꿈을 뜻하는 \n 의 백슬래시가 파일로 만들어지는 과정에서 사라져, 글자가 두 줄로 찢어져 버리는 일이 있다(실제로 발생한 사례다). 코드를 볼 필요 없이 아래를 그대로 넣으면 된다 — "받은 파일을 실행하니 SyntaxError: unterminated string literal 이 떴어. 글자 안에 있던 줄바꿈 기호의 백슬래시가 파일에서 사라진 것 같아. 줄바꿈이 필요한 곳은 백슬래시 대신 chr(10) 을 쓰고, 결과창에 빈 줄이 필요하면 빈 글자를 한 번 더 찍는 방식으로 바꿔서 전체를 통째로 다시 줘." 각 STEP 프롬프트 맨 끝에 이걸 미리 막는 문장이 들어가 있지만, AI가 무시할 때가 있다.
  • 파일을 안 주고 채팅창에 코드만 보여준다 — 이 AI 툴은 질문마다 답하는 모델이 자동으로 바뀐다. 화면 위쪽에서 모델을 Gemini 로 바꾼 뒤 같은 프롬프트를 다시 넣어본다. 그래도 안 되면 각 STEP 의 "정답 코드 파일 받기" 버튼을 쓴다.
  • 앞 단계에서 되던 기능이 사라졌다 — AI가 바뀐 부분만 주면서 나머지를 빠뜨린 것이다. "앞 단계까지 되던 기능을 하나도 빼지 말고 전체를 통째로 다시 줘"라고 다시 요청한다. (각 프롬프트에 이미 그렇게 적혀 있다)
  • 새 대화창에서 물어봤더니 엉뚱한 걸 준다 — AI는 앞서 짜준 코드를 기억하지 못한다. 처음부터 끝까지 같은 대화창에서 이어 물어봐야 한다.
  • 받은 파일이 main (2).py, main (3).py 로 쌓인다 — 정상이다. 이름을 맞추려 애쓰지 말고 방금 받은 가장 최신 파일을 실행한다. 단 폴더는 처음 정한 그대로 쓴다 — 입력해둔 인증키가 프로그램 파일과 같은 폴더에 저장되기 때문이다.

사전 준비가 안 될 때

  • 검은 창이 깜빡하고 바로 닫힌다 — 압축을 안 푼 채 ZIP 안에서 실행한 경우가 대부분이다. 압축을 먼저 푼다.
  • 파란 경고창 Windows의 PC 보호 — 추가 정보 → 실행 을 누르면 된다.
  • 부품 받기가 인증서 오류로 실패 — 설치 파일이 자동으로 한 번 더 시도하게 되어 있다. 그래도 안 되면 사전 준비 페이지 맨 아래 「막히면」 안내를 따른다.
  • 설치 파일 자체가 회사 정책에 막힌다 — 개인이 풀 수 없는 경우가 있다. 화면을 캡처해서 강사에게 보여주는 것이 가장 빠르다.

점검용 파일 두 개 — 실습 폴더의 news-report-bot 안에 있다. 수집이 왜 안 되는지 프로그램과 따로 확인해볼 때 쓴다.

  • 한국뉴스_점검.py — 구글 뉴스와 언론사 RSS가 이 네트워크에서 실제로 되는지 보여준다. 그냥 실행하면 된다.
  • dart_점검.py — DART 가 왜 0건인지 짚어준다. 파일을 열어 인증키와 회사 이름을 채운 뒤 실행한다.
