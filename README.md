# 바이브 코딩 교육

AI에게 프롬프트로 지시해서 실제로 돌아가는 업무 도구를 만들어 보는 사내 실습 교육.

## 과정 목록

### 2시간 단기 — 이슈 리포트 봇 만들기

> [`news-report-bot/`](news-report-bot/) · 소요 120분 · 각자 PC 로컬 실행

키워드를 정해두면 **매일 아침 내 메일함으로 요약 리포트가 오는** 파이프라인을 직접 만든다.

```
DART 공시 ─┐
네이버 뉴스 ─┼─→ 중복 제거 → 아웃룩 발송 → 내 메일함
RSS 피드   ─┘
```

수집 소스를 RSS → 네이버 API → DART 순으로 붙인다. RSS는 API 키가 없어도 돌아가서
**5분 안에 첫 성공**이 나오고, 네이버에서 헤더 인증을, DART에서 파라미터가 많은 실무형 API를
차례로 경험하게 된다. 하나가 막혀도 나머지로 완주할 수 있는 구조다.

**진행 순서 (120분)**

| 시간 | 내용 |
|---|---|
| 10분 | 오프닝 — 완성본이 메일을 보내는 장면 시연 |
| 10분 | 세팅 점검 — 발급받아 온 키를 `.env`에 채우기 |
| 45분 | 실습 1 · 수집 (RSS → 네이버 → DART) |
| 45분 | 실습 2 · 메일 발송 (가장 많이 막히는 구간) |
| 10분 | 마무리 — 매일 자동 실행 예약, 팀별 확장 |

**교육 전에 미리 준비할 것** — 당일에 발급받으면 2시간 중 40분이 날아간다.

- 파이썬 설치 — 아래 **설치 파일 하나 누르기**로 끝난다
- DART 인증키 · 네이버 Client ID/Secret
- **아웃룩(클래식) 로그인 확인** — 사내망은 SMTP를 막아서, 로그인된 아웃룩 앱을 직접 조작해 보낸다 (윈도우 전용)
- 모니터링할 키워드 3개

자세한 발급 절차와 자주 나는 에러 대응은 [`news-report-bot/README.md`](news-report-bot/README.md) 참고.

**실습 안내 페이지** — 당일에는 [`이슈봇만들기.html`](이슈봇만들기.html) 파일 하나만 열어두면 된다.
저장소를 내려받은 뒤 **더블클릭하면 브라우저로 바로 열리는 순수 HTML 파일**이라, 인터넷이
없어도 보인다 (깃허브 화면에서 링크를 누르면 소스 코드로 보이니, 받아서 직접 열 것).
사전 준비 체크리스트부터 단계별 프롬프트·성공 기준·막혔을 때 볼 정답 코드까지 이 한 파일
안에 전부 있다. 코드는 여기 안 담겨 있고, 이 저장소의
[`news-report-bot/`](news-report-bot/)는 그 결과물이 어떻게 생겼는지 보여주는 완성본(정답)일 뿐이다.

## 설치 — 파일 하나만 누르면 끝

이 저장소를 통째로 내려받은 뒤(초록색 `Code` 버튼 → `Download ZIP` → 압축 풀기),
**폴더 안의 파일 하나를 더블클릭**하면 파이썬 설치가 알아서 끝난다.

| 내 PC | 누를 파일 |
|---|---|
| 윈도우 | **`설치.bat`** |
| 맥 | **`설치.command`** |

1~2분 걸린다. 검은 창이 뜨고 글자가 올라가는 동안 **창을 닫지 말 것.**
`설치 끝. 파이썬 준비 완료입니다.` 가 보이면 성공이고, 메모장에 `.env` 파일이 자동으로 열린다.
거기에 발급받은 키를 채워 넣으면 된다.

이 파일이 대신 해주는 일은 딱 두 가지다.

1. 파이썬이 이미 깔려 있는지 확인한다. 없으면 **python.org 공식 배포판**을
   내려받아 설치하고(`PATH 추가` 같은 옵션도 알아서 켠다), 이미 있으면 winget으로
   최신 버전인지 확인해서 오래됐으면 업데이트한다
2. `.env.example` 을 복사해 `.env` 를 만들어 준다 (이미 있으면 덮어쓰지 않는다)

> 라이브러리 설치(`pip install ...`)와 코드 작성은 여기서 하지 않는다. 그건 실습
> 자체의 일부라서, [`이슈봇만들기.html`](이슈봇만들기.html)의 단계별 안내를 따라 직접 한다.

> 설치 파일(.exe)을 저장소에 직접 넣어두지 않은 이유 — 파이썬은 몇 달마다 새 버전이 나오고
> PC마다 필요한 파일이 다르다. 매번 공식 사이트에서 최신판을 받아오는 편이 안전하다.

**막혔을 때**

| 증상 | 해결 |
|---|---|
| 창이 깜빡하고 바로 꺼진다 | 압축을 안 푼 채 ZIP 안에서 실행한 경우다. 압축을 먼저 풀 것 |
| 파란 경고창 `Windows의 PC 보호` | `추가 정보` → `실행` 을 누르면 된다 |
| `winget 이 없습니다` 라고 나온다 | 정상이다. 브라우저가 자동으로 열리니 안내대로 설치하면 된다 |
| 브라우저로 직접 설치할 때 | 첫 화면 맨 아래 **`Add python.exe to PATH` 체크는 필수**다. 빠뜨리면 나중에 실행이 안 된다 |
| 맥에서 파일이 안 열린다 | 터미널에서 `chmod +x 설치.command` 를 한 번 실행한 뒤 다시 더블클릭 |

설치가 다 끝났는지 확인하려면 명령 프롬프트에서 `py -3 --version` (맥은 `python3 --version`).
버전 번호가 나오면 된 것이다.

## 참고

각 과정 폴더의 코드는 **완성본**이다. 실습에서는 이걸 그대로 복사하는 게 아니라
프롬프트로 처음부터 만들어 가고, 막혔을 때 갈아탈 안전망으로 쓴다.

> **주의** — `.env` 파일에는 API 키와 메일 비밀번호가 들어간다.
> 각 폴더의 `.gitignore` 가 `.env` 를 제외하도록 되어 있으니, 그 설정을 지우지 말 것.
